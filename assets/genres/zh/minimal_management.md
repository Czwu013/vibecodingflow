# 极简经营 / 调度（minimal_management）

适用：用极简几何和配色表达系统状态，玩家规划线路、资源或调度的游戏（类 Mini Metro）。

## 验收基准

| 维度 | 4 分是什么样 | 参考对象 |
| --- | --- | --- |
| 能用 | 一局能从开始玩到结束；随机生成稳定，种子可复现；暂停和加速可用 | — |
| 看着 | 极简的形状和配色就传达了全部信息；拥堵和压力在视觉上能提前预警 | 例：Mini Metro 的信息密度控制 |
| 手感 | 拖拽、连线、调整精确且容易撤销；暂停、加速切换顺滑 | — |
| 清晰 | 压力来自哪个站、哪条线一眼可见；失败原因可追溯 | — |
| 想继续 | 压力曲线"刚好来得及处理"；每次规划都有取舍；失败时觉得"下次能做得更好" | — |

## 手感参数起点

| 参数 | 常见起点 | 说明 |
| --- | --- | --- |
| 需求生成速率曲线 | 随时间缓慢递增 | 决定压力节奏 |
| 容量上限 | 按单次可承载量定 | 过载阈值 |
| 乘客 / 任务耐心 | 按线路长度定 | 太短会让失败来得突然 |
| 资源获得节奏 | 如每周获得新线路或车辆 | 要给玩家"重新规划"的时机 |
| 加速倍率 | 1×、2×、4× | 低压时加速、高压时放慢 |
| 随机种子 | 固定可选 | 同一种子必须同一开局 |

## 常见返工点

- 压力曲线陡，失败来得突然而没有预警
- 规划操作繁琐，调整线路太麻烦
- 某一类布局必胜
- 随机性过大，坏种子几乎必死
- 失败后看不出原因

## 体验路线示例

- 开局前 2 分钟 → 能学会连线
- 故意放着不管 → 压力累积到失败的过程有预警
- 用同一种子重开两次 → 开局完全相同
- 在压力较大时调整线路 → 操作不卡、不误触
- 加速和暂停切换 → 状态不丢

## 一分钟测试

一分钟内应当完成第一次连线，并看到第一批乘客被运走。

## 灰盒阶段验什么

圆、方、三角和线。验**压力曲线**和**操作**。压力曲线可以写脚本批量模拟多个种子，看失败时间分布，作为"AI 已验证"的证据。
