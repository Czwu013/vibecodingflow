# 肉鸽 / 幸存者（roguelite_survivors）

适用：一局制、自动攻击或简单攻击、随时间升级选择、局外成长的游戏（类吸血鬼幸存者、轻量肉鸽）。

## 验收基准

| 维度 | 4 分是什么样 | 参考对象 |
| --- | --- | --- |
| 能用 | 一局能从头玩到结算；大量敌人同屏时帧率稳定；局外成长和存档不丢 | — |
| 看着 | 弹幕和敌人很多时，玩家位置、血量、关键危险仍然看得清 | 例：Vampire Survivors 在高密度下的可读性 |
| 手感 | 移动灵活；命中有明确反馈（击退、数字、音效）；升级的瞬间有"我变强了"的感觉 | — |
| 清晰 | 升级选项一眼能看懂收益；死后能回溯"是什么杀了我" | — |
| 想继续 | 一局结束时有"再来一局"的冲动；局外成长看得见；每局构筑有差异 | 例：Vampire Survivors、Hades 的再来一次冲动 |

## 手感参数起点

| 参数 | 常见起点 | 说明 |
| --- | --- | --- |
| 单局时长 | 按项目定，常见 10–30 分钟 | 决定整条数值曲线 |
| 玩家移速 / 生命 / 拾取范围 | 按敌人速度定 | 移速应略快于大多数普通敌人 |
| 敌人生成速率曲线 | 随时间递增 | 前 3 分钟决定留存 |
| 敌人血量、伤害随时间缩放 | 先线性，再调 | 避免数值膨胀失控 |
| 经验需求曲线 | 前几级快，后面放缓 | 前期要很快升到第一级 |
| 武器冷却、伤害、范围 | 每种武器单独一套 | 武器间强度要平衡 |
| 掉落概率 | 按物品稀有度 | |
| 升级可选项数 | 3 选 1 较常见 | 要有真实的取舍 |
| 受击无敌时长 | 0.3–1.0 秒 | 防止被瞬间打死 |

## 常见返工点

- 前 3 分钟太无聊，或太难
- 数值膨胀失控，后期一击秒杀一切
- 升级选项没有真实选择（总有一个明显最优）
- 屏幕太乱，看不清自己和危险
- 武器强度悬殊，只有一两种能玩
- 局外成长拖慢节奏，或让前期失去挑战

## 体验路线示例

- 开局的前 3 分钟 → 敌人逐步增多，第一次升级在合理时间内到来
- 选一个武器方向玩到 10 分钟 → 能感到构筑成型
- 故意不躲，死一次 → 结算清楚，有再来一局的入口
- 屏幕上敌人最多的时刻 → 自己和血条仍然看得清
- 局外成长买一项再开一局 → 能感觉到差别

## 一分钟测试

一分钟内玩家应当击杀第一批敌人并升一次级，体会到"我在变强"。

## 灰盒阶段验什么

方块和圆点，固定几种敌人和三种武器。只验**数值曲线**和**升级选择**是否有真实取舍。数值曲线可以写脚本模拟一局，作为"AI 已验证"的证据。
