# 平台跳跃（platformer）

适用：以跳跃、移动、精确落点为核心的 2D / 2.5D 平台游戏。

## 验收基准

| 维度 | 4 分是什么样 | 参考对象 |
| --- | --- | --- |
| 能用 | 从起点走到终点不崩；碰撞稳定，不卡墙、不穿地；死亡后重生可靠 | — |
| 看着 | 角色、可踩平台、危险物在 1 秒内能区分；起跳和落点的轮廓可读 | 例：Celeste 的画面可读性 |
| 手感 | 按键到起跳没有可感知的延迟；跳跃高度可控（短按低、长按高）；落地利落不飘；有土狼时间和跳跃缓冲，失误时感觉是"我没按好"而不是"游戏吃了我的输入" | 例：Celeste、Super Meat Boy 的操控 |
| 清晰 | 一眼知道哪里能踩、哪里会死；每次死亡都能说出原因 | — |
| 想继续 | 死后 1–2 秒内能重试；每次死亡都学到一点东西；想再来一次 | 例：Super Meat Boy 的重试节奏 |

## 手感参数起点

起点只是常见取值，以手感为准，放进 F9 调参面板里拖。

| 参数 | 常见起点 | 说明 |
| --- | --- | --- |
| 最大移动速度 | 按关卡尺度定 | 先定下来，其他参数围绕它 |
| 加速 / 刹车时间 | 0.05–0.2 秒 | 太长会滑，太短会僵 |
| 跳跃高度 | 约 2–4 个角色身高 | 决定平台间距 |
| 短按截断系数 | 0.4–0.6 | 松开跳跃键时对上升速度的削减 |
| 下落重力倍数 | 1.3–2.0 倍 | 大于 1 能让下落更利落，缓解"飘" |
| 土狼时间 | 0.05–0.15 秒 | 离开平台边缘后仍可起跳的宽容时间 |
| 跳跃缓冲 | 0.08–0.15 秒 | 落地前提前按跳，落地即起跳 |
| 最大下落速度 | 按关卡定 | 防止下落过快穿过地面 |
| 空中控制系数 | 0.6–1.0 | 空中转向能力 |

## 常见返工点

- 跳跃偏飘或偏重（最常见）
- 急停有滑步，折返不灵
- 平台边缘判定太严，差一点就掉
- 死因不明，玩家不知道为什么死
- 镜头跟随抖动或滞后
- 难度曲线陡峭，第一个难点来得太早

## 体验路线示例

- 在平地短按、长按、连按空格各起跳一次 → 高度可控，落地利落
- 左右移动后急停、再折返 → 0.2 秒内停住，没有滑步
- 走到平台边缘再起跳 → 稍晚一点按也能跳起（土狼时间）
- 落地前一瞬间提前按跳 → 落地即起跳（跳跃缓冲）
- 故意掉进坑里 → 1 秒内在检查点重生

## 一分钟测试

新玩家一分钟内应当能跳过第一个坑，并理解"死了会立刻重来"。

## 灰盒阶段验什么

只用方块角色和矩形平台。这一阶段只验**手感**和**重试节奏**两件事，通过之前不放任何美术、音效、特效。
