# 塔防（tower_defense）

适用：在路径或地图上放置防御单位、抵御分波敌人的游戏。

## 验收基准

| 维度 | 4 分是什么样 | 参考对象 |
| --- | --- | --- |
| 能用 | 完整一局能通关或失败；放置、出售、升级不出 bug；寻路有效 | — |
| 看着 | 塔的种类、射程、敌人血量一眼分得清 | — |
| 手感 | 放塔顺手，取消和出售不误触；暂停和加速可用；命中有反馈 | — |
| 清晰 | 漏怪时知道是为什么（哪类敌人、哪里缺口）；数值信息随手可查 | — |
| 想继续 | 每一波都有决策（买什么、放哪）；前期选择影响后期；通关后想试别的构筑 | 例：Bloons TD、Kingdom Rush 的构筑决策 |

## 手感参数起点

| 参数 | 常见起点 | 说明 |
| --- | --- | --- |
| 塔：成本 / 射程 / 攻速 / 伤害 | 每种塔单独一套 | 每种塔要有自己的角色 |
| 升级曲线 | 成本递增快于收益递增 | 避免只升一座塔 |
| 出售返还比例 | 60%–80% | 太高会让试错无成本 |
| 敌人：血量 / 速度 / 护甲 | 每类敌人单独一套 | 类型要逼迫玩家换思路 |
| 每波数量曲线 | 逐波递增 | 前几波要轻松 |
| 波次间隔 | 可跳过 | 让熟练玩家不用等 |
| 初始金币 / 每波收入 | 按首波能放 2–3 座塔定 | |
| 游戏倍速选项 | 1×、2×、3× | |

## 常见返工点

- 某一种塔是最优解，选择变成假的
- 前几波太无聊，或开局就压力过大
- 后期数值爆炸
- 路径被堵死或绕路的 bug
- 看不清射程范围

## 体验路线示例

- 前 3 波轻松放塔 → 操作顺手，反馈清楚
- 第 5–8 波开始有压力 → 需要做出决策
- 只用一种塔打到失败 → 应当在某一波失败（没有万能解）
- 暂停、加速、出售各试一次 → 都正常
- 漏掉一只怪 → 能看出是哪里的缺口

## 一分钟测试

一分钟内放下第一座塔，并看着它击杀一只敌人。

## 灰盒阶段验什么

几何图形的塔和敌人。验**数值曲线**和**决策多样性**。可以写脚本模拟多种构筑自动对战，看是否存在唯一最优，作为"AI 已验证"的证据。
