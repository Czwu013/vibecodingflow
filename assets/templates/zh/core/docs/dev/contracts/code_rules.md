# 代码规则

## 运行环境
1. {{例：双击 index.html 即可运行，不需要服务器（原因：人验收时零门槛）}}
2. {{例：离线运行，不从网上加载资源（原因：可复现、合规）}}

## 代码组织
3. 可调参数只放配置文件，不散落在代码里（原因：人要能现场调手感，AI 改参数不用动逻辑）。
4. 界面文字只放语言文件，所有语言同时加。
5. 单个文件超过约 500 行就拆分，拆分单独作为一次改动（原因：拆分混在功能改动里无法验收）。

## 可验收性
6. 遵守 `contracts/feedback_friendly.md`：一键复制调试信息、调参面板、一键到被验收的状态。
7. 每个里程碑的体验路线不超过 10 分钟，超过就拆成两个里程碑。

## 合规
8. {{例：不使用他人商标、素材}}

## 每次改动的收尾
9. 无报错；至少一张截图或一次运行记录作为证据（放 `plans/evidence/`）。
10. 更新 CURRENT_STATE、plans、验收卡；里程碑最多标到「待验收」。
