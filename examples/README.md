# Examples / 示例

`sample-platformer/` is a **sample project generated with `init.py --genre platformer`**, then given two review rounds
(round 1 = 返工 because the jump feels floaty, round 2 = 通过).

**All data in it is illustrative, not from a real project.** It exists so you can run
`python docs/dev/tools/check_docs.py --stats` and open `docs/dev/reviews/M1_r1.md` to see what the artifacts look like.

**`sample-platformer/` 是示例,不是真实项目的数据。** 它由 `init.py --genre platformer` 生成,再补了两轮验收卡
(第 1 轮返工、第 2 轮通过),用来让你直接看到文档和统计长什么样。
