# 游戏规则

1. **确定性。** 所有随机走带种子的随机数，同一个种子同样的结果。
   *原因：复现 bug；也只有这样，调参前后的对比才公平。*
2. **逻辑与帧率无关。** 用固定时间步长或按 delta 时间推进，不能依赖机器帧率。
   *原因：手感是调出来的，帧率一变手感就变，人的反馈就失效了。*
3. **手感参数全部进配置，带范围。** 速度、加速度、重力、跳跃、冷却、伤害、动画时长都在配置里，并出现在 F9 调参面板。
   *原因：“太飘”要靠拖滑块解决，不要靠描述来回改代码。*
4. **先灰盒，后美术。** 核心循环和手感的验收通过之前，不上美术、音效、特效。
   *原因：这三样一旦做了，推翻玩法的代价就翻几倍。*
5. **存档带版本号。** 改存档结构必须写迁移，或明确废弃旧存档并记入 DECISIONS。
   *原因：玩家（和你自己）的旧存档不应该在更新后悄悄坏掉。*
6. **有直达关卡的调试入口。** `?scene=xxx&seed=xxx` 或快捷键，直达被验收的场景。
7. **性能预算。** 目标帧率 {{60}} FPS；低于预算时先在 `bench/` 记录实测，再优化。
8. **素材登记。** 每个素材（含 AI 生成的）登记来源和授权到 `ledgers/assets_ledger.md`。
   *原因：上架审核和版权核查要用。*
