# 反馈友好性规则

目标：人体验之后，用最少的字把问题说清楚；AI 拿到反馈后，不用追问就能复现和修改。

1. **一键复制调试信息。** 快捷键 F8（或界面角落按钮）把以下内容复制到剪贴板：版本 / 里程碑号、随机种子、当前场景和关键状态摘要、最近 20 条事件、控制台错误。
   *原因：人描述“我做了什么”很难完整；复制一次，AI 就有复现条件。*
2. **主观手感参数可现场调。** 速度、加速度、重力、跳跃、冷却、动画时长、缓动、颜色、间距……放进调参面板（F9 或 `?debug=1`），实时拖动生效，并有「复制当前参数」按钮，输出成可直接粘进配置文件的片段。
   *原因：“太飘”“太快”靠嘴说要来回五六轮；人拖到顺手，把数字贴回来，一轮结束。*
3. **一键到被验收的状态。** 通过 URL 参数或快捷键直达被验收的场景（`?scene=boss&seed=123`），人不用每次从头走。
   *原因：验收时间花在体验目标上，而不是重复开局。*
4. **可重复的起点。** 随机全部走带种子的随机数，同一个种子得到同样结果。
5. **版本可见。** 界面角落显示版本 / 里程碑号，反馈才对得上哪一版。
6. **一键重置。** 清空存档和状态，回到干净起点。

验收卡的「怎么跑起来」里要写明这些入口怎么用。
